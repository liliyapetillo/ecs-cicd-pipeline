### Cross-menu ordering: mixing 2-serving and 4-serving items (Blue Apron)

## 5. How Liliya Approaches Common QA Questions

These reflect answers she has validated in interview practice. They describe her approach and reasoning, and can be used for "how would you" or "how do you" questions.

### Test strategy from scratch
Start with requirements and an understanding of the product, use insights from grooming and ticket breakdown, align the test plan to the tickets, layer coverage from happy path to negative cases to edge cases, then prioritize and schedule by risk.

### Designing an API test suite
Contract and schema first, then happy path, then negative testing, then edge cases and boundary values as an explicit fourth layer (empty arrays, maximum-length strings, zero and negative numbers).

### Validating an API response beyond the status code
Check the response body, the request itself, the database state, downstream effects, authorization, compliance concerns, the contract, and the schema.

### Error-handling testing
Correct status code, a clear and useful error message, no crash or silent failure, and no leaking of sensitive internal details such as stack traces.

### How she uses AI in QA
- She uses a structured prompting approach she calls SMART prompting: role, context, task, format, and constraints. She applies it to requirements analysis, test case generation, test planning, and coverage gap and edge-case analysis.
- She always reviews AI output against the requirements and the coverage matrix before trusting it. She sees vague prompts combined with blind trust as the main failure mode, and she is careful about exposing personal or proprietary data to tools that lack enterprise protections.
- To introduce AI to a team that has none, she would map usage scenarios first, sort them into easy, templated starting points (test case generation, test plan generation, coverage gap analysis), then run a lunch-and-learn or demo.
- AI-assisted coding: at Hubble she used GitHub Copilot to generate and maintain the Cypress automation scripts in her JavaScript framework.
